# Whitford Global College – Merit Points & Digital Credentials

A DApp for a fictional college, built for the NCI Blockchain Technologies project. It runs on the Ethereum Sepolia testnet.

- **WhitfordPoints (ERC-20, WGCP):** non-transferable Merit Points. Contract `0xdc97640C2Beb1e09f82A570f71ff90855BC2584d`
- **WhitfordCredential (ERC-721, WGCCRED):** soulbound degree credentials. Contract `0x1F553b6E6589b19E30674a633E8eeAF8265b5157`

Open the site, connect MetaMask on Sepolia, and use the Student Hub, Verify and Registrar's office sections.
The Registrar's office unlocks only for the registrar wallet.
